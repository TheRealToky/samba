# Web frontend — Phase 5

Placeholder for the React + TypeScript + Vite dashboard (deployment diagram:
the client behind the load balancer / 3 web servers).

**Planned (Phase 5):**
- Interactive map of Madagascar (MapLibre GL + deck.gl) with region-level layers:
  satellite/NDVI, climate, species density.
- Risk heatmaps and trend dashboards (deforestation rate, species richness,
  temperature anomaly) — Recharts.
- Report export (CSV/PDF) and the environmental alert feed.
- Built for non-technical users (NFR-4); talks only to the backend API over HTTPS.
